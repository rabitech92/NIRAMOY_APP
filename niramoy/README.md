# নিরাময় — ফার্মেসি ব্যবস্থাপনা (Spring Boot)

Java 17 · Spring Boot 3.3 · Spring Security · Spring Data JPA · MySQL · Thymeleaf

`Pharmacy_Management.html` প্রোটোটাইপকে একটি আসল, ডাটাবেস-ভিত্তিক ওয়েব অ্যাপে রূপান্তর করা হয়েছে।

## চালানোর নিয়ম

```bash
# ১) MySQL চালু থাকতে হবে (schema `niramoy` না থাকলে নিজে তৈরি হবে)
# ২) চালান
mvn spring-boot:run
# ৩) ব্রাউজারে http://localhost:8080
```

ডাটাবেস সেটিংস (`src/main/resources/application.yml`): schema `niramoy`, user `root`, password `Admin123`।
Environment variable দিয়ে বদলানো যায়: `DB_HOST`, `DB_PORT`, `DB_USERNAME`, `DB_PASSWORD`।

## ডেমো লগইন (প্রথমবার চালালে তৈরি হয়)

পাসওয়ার্ড সবার: `Niramoy@123` (`SEED_PASSWORD` দিয়ে বদলানো যায়)

## নিরাপত্তা ও ডিজাইন সিদ্ধান্ত

- BCrypt পাসওয়ার্ড, ফর্ম লগইন, CSRF চালু (POS fetch-ও টোকেন পাঠায়)।
- ভূমিকাভিত্তিক URL অনুমতি (`SecurityConfig`) এবং মেনুতেও একই নিয়ম।
- শাখা-সীমিত ব্যবহারকারী সবসময় নিজের শাখায় আটকে থাকেন (`BranchScope`); শুধু SUPER_ADMIN/OWNER শাখা বদলাতে পারেন।
- স্টক কমানো একটি অ্যাটমিক `UPDATE ... WHERE stock >= qty` দিয়ে, তাই একসাথে দুজন বিক্রি করলেও ওভার-সেল হয় না।
- মেয়াদোত্তীর্ণ ব্যাচ POS-এ দেখায় না এবং সার্ভারও বিক্রি আটকায়।
- ইনভয়েসে নাম/দাম/ক্রয়মূল্যের স্ন্যাপশট থাকে, পরে ওষুধ বদলালেও ইনভয়েস ঠিক থাকে।
- সব টাকার অঙ্ক `BigDecimal`, `@Version` দিয়ে optimistic locking।
