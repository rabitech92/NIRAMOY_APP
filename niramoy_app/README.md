# নিরাময় ফার্মেসি — মোবাইল অ্যাপ (Flutter)

Spring Boot ফার্মেসি সফটওয়্যারের সাথে কাজ করা অ্যান্ড্রয়েড অ্যাপ। ফোনে ড্যাশবোর্ড, ওষুধের স্টক, POS বিক্রয়,
ইনভয়েস, বকেয়া আদায় ও রিফিল সাবস্ক্রিপশন দেখা ও পরিচালনা করা যায়।

## আগে সার্ভারে (Spring Boot) যা করতে হবে
1. `niramoy-patch.zip`-এর `src` প্রজেক্টে বসান (এতে `/api/v1` REST API ও JWT লগইন আছে)।
2. `application.yml`-এ একটি গোপন কী দিন (না দিলে সার্ভার রিস্টার্টে সবাইকে আবার লগইন করতে হবে):
   ```yaml
   niramoy:
     api:
       secret: "এখানে-কমপক্ষে-৩২-অক্ষরের-যেকোনো-দীর্ঘ-গোপন-লেখা-বসান"
       token-hours: 336   # লগইন ১৪ দিন থাকবে
   ```
3. সার্ভার চালু করুন (`mvn spring-boot:run`)। ব্রাউজারে `http://localhost:8080/api/v1/me` খুললে `401` JSON এলে API ঠিক আছে।

## APK বানানোর দুটি উপায়

### উপায় ১: GitHub Actions (PC-তে Flutter না থাকলেও চলবে) — সবচেয়ে সহজ
1. GitHub-এ একটি নতুন রিপোজিটরি বানিয়ে এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডারসহ) আপলোড/পুশ করুন।
2. GitHub → **Actions** → **Build APK** → **Run workflow**।
3. ৫–১০ মিনিট পর রান শেষে নিচে **Artifacts → niramoy-apk** ডাউনলোড করুন; ভেতরে `app-release.apk`।

### উপায় ২: নিজের PC-তে
1. [Flutter SDK](https://docs.flutter.dev/get-started/install) ইনস্টল করুন এবং `flutter doctor` ঠিক করুন (Android toolchain সবুজ হতে হবে)।
2. এই ফোল্ডারে টার্মিনাল খুলে চালান: Windows-এ `build_apk.bat`, Linux/Mac-এ `./build_apk.sh`।
3. APK পাবেন: `build/app/outputs/flutter-apk/app-release.apk`।

> `android/` ফোল্ডার ইচ্ছে করে রাখা হয়নি; স্ক্রিপ্ট/CI `flutter create` দিয়ে তৈরি করে তারপর `android_overrides/AndroidManifest.xml` বসায়
> (এতে ইন্টারনেট অনুমতি ও LAN-এর http সংযোগের অনুমতি আছে)।

## ফোনে ইনস্টল ও সংযোগ
1. `app-release.apk` ফোনে পাঠান, খুলে ইনস্টল করুন ("অজানা উৎস থেকে ইনস্টল" অনুমতি লাগতে পারে)।
2. **PC ও ফোন একই Wi-Fi-তে** থাকতে হবে।
3. PC-র IP বের করুন: `ipconfig` → IPv4 Address (যেমন `192.168.0.105`)।
4. Windows ফায়ারওয়ালে ৮০৮০ পোর্ট খুলুন (Administrator PowerShell):
   ```powershell
   netsh advfirewall firewall add rule name="Niramoy 8080" dir=in action=allow protocol=TCP localport=8080
   ```
5. অ্যাপ খুলে লগইন পেজের **সার্ভার সেটিংস**-এ দিন `http://192.168.0.105:8080` → **সংযোগ পরীক্ষা** → সংরক্ষণ।
6. লগইন করুন (ওয়েবের একই ইউজারনেম/পাসওয়ার্ড)।

অ্যান্ড্রয়েড এমুলেটরে চালালে ঠিকানা `http://10.0.2.2:8080` (ডিফল্ট)।

দোকানের বাইরে (মোবাইল ডেটায়) ব্যবহার করতে হলে সার্ভারকে ইন্টারনেটে HTTPS ডোমেইনসহ হোস্ট করতে হবে;
তখন অ্যাপে `https://আপনার-ডোমেইন` দিন (এবং চাইলে manifest-এ `usesCleartextTraffic` মুছে দিন)।

## ফিচার
| ট্যাব/পেজ | কী করা যায় |
|---|---|
| ড্যাশবোর্ড | আজকের বিক্রয়/লাভ, বকেয়া, কম স্টক, মেয়াদ ঘনিয়ে আসা, রিফিল ডিউ, ৭ দিনের চার্ট, সাম্প্রতিক বিক্রয় |
| ওষুধ ও স্টক | নাম/জেনেরিক/কোম্পানি/বারকোড/বক্স দিয়ে খোঁজা, ফিল্টার (কম স্টক, মেয়াদ), বিস্তারিত |
| বিক্রয় (POS) | খুঁজে পিস/পাতা কার্টে যোগ, পরিমাণ হাতে লেখা, গ্রাহকের নাম+মোবাইল (আবশ্যক), পেমেন্ট (ক্যাশ/বিকাশ/নগদ/রকেট/ব্যাংক/কার্ড/বকেয়া), আংশিক পরিশোধ |
| ইনভয়েস | তালিকা, বিস্তারিত, রসিদ কপি (WhatsApp/SMS-এ পাঠাতে) |
| আরও | **খরচ ব্যবস্থাপনা** (ড্যাশবোর্ড, নতুন খরচ, তালিকা/রিপোর্ট, বাকি পরিশোধ, বাতিল), রিফিল সাবস্ক্রিপশন ও এক ক্লিকে বিল, বকেয়া আদায়, সাবস্ক্রিপশনের অবস্থা, সার্ভার সেটিংস, লগআউট |

**গ্রাহক বিশ্লেষণ** (আরও → গ্রাহক বিশ্লেষণ; মালিক/সুপার অ্যাডমিন/ম্যানেজার): কে জীবনকালে কত টাকার ওষুধ কিনেছেন, আজ/সপ্তাহ/মাস/বছর, দৈনিক-সাপ্তাহিক-মাসিক-বার্ষিক তালিকা, সবচেয়ে বেশি কেনা ওষুধ ও কেনাকাটার প্রিভিউ।
**ক্রয়-বিক্রয় ও স্টক হিসাব** (আরও → ক্রয়-বিক্রয় ও স্টক হিসাব; মালিক/সুপার অ্যাডমিন/ম্যানেজার): স্টকে এখন কত টাকার মাল (ক্রয়/বিক্রয়মূল্যে), মেয়াদোত্তীর্ণ ও শীঘ্র মেয়াদ শেষ মাল, মাসিক (১২ মাস) ও বার্ষিক ক্রয়-বিক্রয়-লাভ, ক্যাটাগরি/শাখা/ওষুধ অনুযায়ী স্টকের মূল্য।
**বেশি বিক্রিত ওষুধ** (আরও → বেশি বিক্রিত ওষুধ): সময়/সাজানো অনুযায়ী র‍্যাংকিং, বর্তমান স্টক ও "কম" সতর্কতা, ⭐ চিহ্নিত করা/তোলা, শীর্ষ N একসাথে চিহ্নিত। ⭐ ওষুধ স্টক, POS ও ওষুধের বিস্তারিত পেজে ব্যাজসহ দেখায়।

**বারকোড স্ক্যান:** POS ও ওষুধ-স্টকের সার্চ বক্সে 📷 আইকন। POS-এ স্ক্যান করলে ওষুধ মিললে সঙ্গে সঙ্গে ১ পিস কার্টে যোগ হয়।
**খরচ ব্যবস্থাপনা** শুধু মালিক/সুপার অ্যাডমিন/শাখা ম্যানেজারের জন্য; খরচ বাতিল শুধু মালিক/সুপার অ্যাডমিন করতে পারেন।

ভূমিকা অনুযায়ী ট্যাব বদলায় (ক্যাশিয়ার শুধু POS/ইনভয়েস, ইনভেন্টরি ম্যানেজার শুধু স্টক ইত্যাদি)।
লাভ ও ক্রয়মূল্য শুধু মালিক/সুপার অ্যাডমিন/ম্যানেজারকে দেখানো হয়। মালিক ওপরের 🏬 আইকন থেকে শাখা বদলাতে পারেন।

## নিরাপত্তা ও সীমাবদ্ধতা (সৎভাবে)
- লগইন টোকেন (JWT) `flutter_secure_storage` দিয়ে এনক্রিপ্টেড (Android Keystore) স্টোরেজে থাকে।
- অ্যাপের জন্য সর্বনিম্ন Android ৭.০ (API 24) দরকার।
- ৫ বার ভুল পাসওয়ার্ডে ৫ মিনিট লগইন বন্ধ থাকে (সার্ভারে)।
- সাবস্ক্রিপশনের মেয়াদ শেষ হলে (গ্রেস সহ) সার্ভার API-ও বন্ধ করে দেয়, অ্যাপে ত্রুটির বার্তা আসে।
- অফলাইন মোড, পুশ নোটিফিকেশন, ব্লুটুথ থার্মাল প্রিন্টার, বিক্রয় ফেরত, ক্রয় তালিকা (MPO) ও ওষুধ যোগ/স্টক সমন্বয় এখনো মোবাইলে নেই — এগুলো ওয়েবে আছে।
- Play Store-এ দিতে হলে নিজের keystore দিয়ে সাইন করতে হবে; এখনকার APK ডিবাগ কী দিয়ে সাইন করা, সাইডলোডের জন্য যথেষ্ট।
